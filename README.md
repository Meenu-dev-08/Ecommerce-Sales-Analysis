# E-Commerce Sales Analysis & Demand Prediction

Analyzed e-commerce sales data using Python to identify trends and demand patterns. Built machine learning models (Linear Regression &amp; Random Forest) to predict product demand and support inventory optimization.

## 📊 Project Overview

This project analyzes e-commerce sales data to identify trends and predict future demand.

## 🛠 Tools Used

- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## 📈 Key Features

- Sales trend analysis
- Top product identification
- Demand forecasting using ML
- Model comparison (Linear Regression vs Random Forest)

## 📌 Results

Random Forest performed better than Linear Regression in predicting demand.

## 🚀 Outcome

Helps businesses optimize inventory and improve decision-making.
